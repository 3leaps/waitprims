# waitprims v0.1.1

Infrastructure release: a Rust-only signed-release kit. No API change is
intended. This commit is the release-prep content; it does not create a
git tag, publish to crates.io, or change repository visibility.

## Highlights

- **VERSION is SSOT**: workspace crates sync from `VERSION` via
  `make version-sync` / `make version-check`.
- **Makefile release targets**: `release-preflight`, `release-check`,
  `release-clean`, `release-download`, `release-checksums`,
  `release-sign`, `release-export-keys`, `release-verify`,
  `release-notes`, `release-upload`.
- **Local MFA signing**: CI drafts an unsigned GitHub release. A human
  signs checksums with minisign/PGP and uploads. CI does not hold
  signing keys.
- **CLI archives** for the five platforms this repo already smokes:
  linux-amd64, linux-arm64, darwin-arm64, windows-amd64, windows-arm64.
  No musl, no macOS Intel, no FFI tarball.
- **SBOM + licenses** attached to the draft release when the tag
  workflow runs.
- **`make release-check`** runs `cargo package` and does not run
  `cargo publish`. Workspace `publish` stays `false`. Dependent crates
  stay path+version ready for a later crates.io enablement.
- **Repository metadata** added so crates.io can be enabled later.

## Not in this release

- No Go bindings workflow or path-prefixed module tag
- No TypeScript / npm / N-API
- No FFI tarball or committed `.a`
- No crates.io publish
- No visibility change
- No git tag in this commit
