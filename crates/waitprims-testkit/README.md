# waitprims-testkit

Deterministic test helpers for waitprims: a logical `FakeClock` and
scripted observers. Proofs stay off the network.

```toml
waitprims-testkit = "0.1"
```

Depends on [`waitprims-core`](https://crates.io/crates/waitprims-core)
and [`waitprims-async`](https://crates.io/crates/waitprims-async).
Docs: <https://docs.rs/waitprims-testkit>
